# CodeAlpha_Sales_Prediction
Sales Prediction using Python and Machine Learning


CodeAlpha – Sales Prediction Using Python

About the Project

This project predicts product sales based on advertising expenditure using Machine Learning.

Dataset

Advertising dataset containing:

* TV
* Radio
* Newspaper
* Sales

Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

Algorithm

Linear Regression

Project Features

* Data cleaning
* Exploratory Data Analysis
* Data visualization
* Sales prediction
* Model evaluation
* Advertising impact analysis
* Marketing recommendations

Results

The model predicts sales based on advertising expenditure and evaluates its performance using MAE, MSE, RMSE and R2 Score.

Conclusion

This project demonstrates how Machine Learning can help businesses analyze advertising effectiveness and make better marketing decisions.
